# Router runs, 2026-10-25

Same harness as `2026-10-25-matrix.md`, with the agent-context-router server enabled in each isolated root, plus a delegate scenario. Every run also had the `summon` extension for delegation. Five runs per cell.

## Three rounds

1. **v1** (`2026-10-25-router-v1.jsonl`): policy offered the router and a direct file read as equal options. Every check passed 20/20 (after fixing the harness to recognize Code Mode's `loadModule` spelling), but the agent read the file directly in 18 of 20 runs, skipping sync, sha and logging.
2. **v2** (`2026-10-25-router-v2.jsonl`): policy made the router the default. Router used in 18/20, checks 19/20 (one PR description put a title line above "For reviewers"). Input tokens rose 40 to 75% over v1: the agent called `list_functions`, guessed the parameter name `id`, failed, then called `get_function_details` and retried with `module_id`.
3. **v3** (`2026-10-25-router-v3.jsonl`): parameter renamed to `id`, and the policy gives the exact Code Mode call. Router used 20/20, zero discovery calls, every check 20/20.

## v3 compared with the full policy (median input tokens)

- **device-install:** 84,964 vs 206,044 (full, `2026-10-25-matrix-full.jsonl`)
- **pr-description:** 60,782 vs 180,964
- **review-comment:** 61,231 vs 117,576
- **delegate-device:** 139,984 vs 265,154 (full, `2026-10-25-delegate-full.jsonl`). The subagent loaded `device-testing` itself before any device command 5/5.

Router log, v2 and v3: every load synced with status `current`.

## Limits

Five runs per cell in a tiny fixture; real sessions carry much more conversation and tool output, so real savings will be smaller in percentage terms. Narrow checks. The full-policy delegate runs couldn't load a module (there are none), so "subagent loaded the module" doesn't apply to them; their device behavior passed 5/5.

## What the rounds showed

- An agent will take the cheapest path the policy allows, so a fallback has to be named as a fallback.
- Code Mode tool discovery costs whole round trips. The always-loaded text should give the exact call for any tool it expects the agent to use.
