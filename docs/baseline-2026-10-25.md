## Known duplication (not caused by the policy itself)

goose reloads a parent AGENTS.md for every new subdirectory the agent touches (`load_hints.rs`, per-directory dedupe). In one session the project AGENTS.md loaded four times and the global policy twice. Tracked separately: aaif-working-groups #2.

## Where a real request's system prompt goes (2026-10-25)

One request from this machine's goose logs (`llm_request.9.jsonl`, a Code Mode session): system prompt 174,256 bytes, tool definitions 12,634 bytes.
- Ten "Subdirectory Hints" sections take about 112KB before the global hints begin. They include the global policy a second time and the AGENTS.md of other repos the session touched (one of them about 20KB).
- The global policy proper: about 60KB.
- With Code Mode on, goose skips extension instructions, so the skills listing isn't in the prompt.

In a session without Code Mode (the isolated harness smoke test), the `skills` extension instructions list 1,010 skills in about 292KB, roughly 73k tokens per request. Any delegate or client without Code Mode pays that. It's a bigger lever than the policy itself, and it's a candidate module: list skills on demand instead of up front.
